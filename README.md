# 🧳 智能旅行助手 Agent

《Hello Agents》第一章 1.3 节实践项目 —— 基于 Thought → Action → Observation 循环的智能体。

## 功能

- 查询指定城市的实时天气
- 根据天气推荐旅游景点
- 支持 **CLI 命令行** 和 **Web 网页** 两种交互方式

## 在线体验

👉 [travel-agent-production-e21d.up.railway.app](https://travel-agent-production-e21d.up.railway.app)

无需部署，浏览器打开即可使用。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置密钥

复制 `.env.example` 为 `.env`，填入你的 API 密钥：

```bash
cp .env.example .env
```

需要申请的服务：
- [DeepSeek API](https://platform.deepseek.com/) — LLM 模型
- [Tavily API](https://tavily.com/) — 景点搜索

### 3. 运行

#### CLI 模式（终端交互）

```bash
python FirstAgentTest.py
```

运行后输入任务，回车执行；输入 `q` 退出。

#### Web 模式（浏览器）

```bash
python FirstAgentTest.py --web
```

打开浏览器访问 `http://127.0.0.1:5000`

## 部署到云端

本应用已适配 [Railway](https://railway.app/) 云平台，支持一键部署。

1. 将代码推送到 GitHub
2. 在 Railway 新建项目 → 关联 GitHub 仓库
3. 设置 **Start Command** 为 `python FirstAgentTest.py --web`
4. 在 **Variables** 中添加环境变量（参考 `.env.example`）

## Agent 逻辑设计详解

### 一、六大板块总览

```
┌─────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────┐
│  板块二：工具定义                                     │
│  get_weather() 和 get_attraction() 两个工具函数      │
│  + available_tools 路由字典                          │
│  → 相当于"双手"，真正干活的地方                       │
└─────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────┐
│  板块三：LLM 客户端                                   │
│  OpenAICompatibleClient 类                           │
│  → 相当于"大脑"，封装调用 DeepSeek API 的细节         │
```

### 二、Agent 主循环（run_agent）—— 核心中的核心

`run_agent()` 实现了 **Thought → Action → Observation** 的闭环，是智能体的核心工作机制。

```
                             用户输入
                                │
                                ▼
                    ┌──────────────────────┐
                    │    prompt_history     │
                    │  ["用户请求: xxx"]     │
                    └──────────┬───────────┘
                               │
                    ┌──────────▼───────────┐
           ┌─────── │   for i in range(5)  │ ← 最多 5 轮
           │        └──────────┬───────────┘
           │                   │
           │                   ▼
           │         ╔══════════════════════╗
           │         ║  ① 思考（Thought）   ║
           │         ║  将历史拼成完整消息    ║
           │         ║  → 调用 DeepSeek API ║
           │         ║  → 得到 Thought+Action║
           │         ╚══════════════════════╝
           │                   │
           │                   ▼
           │         ╔══════════════════════╗
           │         ║  ② 解析 Action       ║
           │         ║  正则提取 Action: 内容 ║
           │         ╚══════════════════════╝
           │                   │
           │          ┌────────┴────────┐
           │          │  有 Action 吗？  │

           │               ╱     ╲
           │             ╱         ╲

           │       │记录 │     ┌────────┴────────┐
```

### 四、两个核心机制

#### 1. 工具路由机制

LLM 输出的是**字符串**（如 `"get_weather"`），程序通过 `available_tools` 字典找到真正的 Python 函数来执行：

```
LLM 输出: Action: get_weather(city="北京")
                    │
                    ▼ 正则解析
        tool_name = "get_weather"
        kwargs = {"city": "北京"}
                    │
                    ▼ 字典路由
        available_tools["get_weather"]
                    │
                    ▼ 调用
        get_weather(city="北京")  →  "北京当前天气：晴天，26℃"
```

#### 2. 短期记忆机制

`prompt_history` 是一个列表，记录了完整的 Thought → Action → Observation 历史，每次调用 LLM 时都发给它：

```
prompt_history = [
    "用户请求: 查北京天气",
    "Thought: 先查天气\nAction: get_weather(city=\"北京\")",
    "Observation: 北京当前天气：Sunny，气温26摄氏度",
    "Thought: 现在推荐景点\nAction: get_attraction(city=\"北京\", weather=\"Sunny\")",
    "Observation: 推荐颐和园、长城...",
]
```

这让 LLM 在下一轮决策时可以"看到"自己之前做了什么、得到了什么结果，从而做出合理的下一步判断。每次新任务清空历史，避免旧任务干扰新任务。

### 五、错误处理策略

| 场景 | 处理方式 |
|------|---------|
| LLM 输出格式不对（没有 Action） | 记录 Observation 错误信息，让 LLM 下一轮修正 |
| 网络请求失败 | try-except 捕获异常，返回友好错误信息 |
| LLM 一次输出多对 Action | 安全截断，只保留第一对 |
| 超过 5 轮循环 | 自动结束，防止无限循环 |
